# Contributing

Open a focused issue or pull request with the problem, proposed change, and evidence. Good first areas: compatibility with newer Codex session formats, clearer onboarding, and destination-open verification.

Preserve these invariants: originals stay intact; each transfer uses a fresh workspace; public keys are pinned independently; completion requires a signed receipt and verified files/history; uncertain native mutations are reconciled before retrying.

Never submit real chats, transfer manifests, authentication files, private signing keys, or unredacted logs. Use synthetic sessions and temporary folders for tests. See [development](docs/DEVELOPMENT.md).
